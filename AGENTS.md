# Правила для работы с YDiskSaver

- Поддерживайте `ChangeLog` в актуальном состоянии: при изменении поведения программы, параметров командной строки или исправлении ошибок обновляйте запись соответствующей версии в том же изменении.
- Не открывайте и не выводите содержимое пользовательских HAR, файлов сессии и cookies. Для проверок используйте искусственные данные.
